# 绿伴校园 —— 绿植领养与交换系统

基于 SSM + MySQL + JSP 开发的校园绿植共享平台，为高校师生提供线上绿植领养、闲置交换与养护交流服务，实现校园绿植资源的高效流转。

---

## 🛠️ 技术栈
- **后端**：Java, Spring, SpringMVC, MyBatis
- **数据库**：MySQL 5.7
- **前端**：JSP, HTML, CSS, JavaScript
- **服务器**：Tomcat 8.5
- **构建工具**：Maven

---

## ✨ 核心功能
### 用户端功能
- 账号注册与登录
- 绿植领养申请与进度查询
- 闲置绿植发布与交换
- 个人中心（收藏、消息通知、养护记录）

### 管理员端功能
- 领养/交换申请审核
- 绿植信息管理（新增、编辑、下架）
- 用户账号管理
- 数据统计与公告发布
